# Support and Troubleshooting

This is a self-study repository, not a hosted database service.

1. Read the relevant module and the environment setup guide.
2. Check the official PostgreSQL documentation for version-specific behaviour.
3. Reproduce the issue with the provided sample schema.
4. When reporting a repository issue, include PostgreSQL version, operating system, exact SQL, expected result, actual result, and sanitized error output.
5. Never include passwords, tokens, private customer data, or production database dumps.

For local setup issues, start with `setup/README.md` and inspect `docker compose logs postgres`.
